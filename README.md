# Forgeweave

Forgeweave is an independent NeoForge mod inspired by the 1.12.2 generation of [Tinkers' Construct](https://github.com/SlimeKnights/TinkersConstruct/tree/1.12), commonly known as Tinkers' Construct 2.

The project aims to bring that generation's modular tool building, material traits, modifiers, melting, alloying, and casting experience to modern Minecraft while developing under its own name and identity.

> [!IMPORTANT]
> Forgeweave is unofficial and is not a SlimeKnights project. Please do not send Forgeweave support requests to the Tinkers' Construct team.

## Status

Forgeweave is in early development. There are no playable releases yet.
