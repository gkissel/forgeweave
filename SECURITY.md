# Security policy

## Supported versions

Forgeweave has not published a playable release yet. Supported release lines will be listed here after the first release.

## Reporting a vulnerability

Do not open a public issue for vulnerabilities, exploits, malicious network behavior, or problems that could compromise players or servers.

Use GitHub's **Report a vulnerability** option in the repository's Security tab to submit a private report. Include affected versions, impact, reproduction steps, and any proposed mitigation. Please allow maintainers time to investigate before public disclosure.

Ordinary crashes and gameplay bugs should use the public bug-report template instead.
